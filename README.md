# Sunchucks legal and support pages

Public account-level GitHub Pages site for the Sunchucks iOS app. The
account-level hostname keeps `app-ads.txt` at the domain root, as required by
AdMob's app verification when this URL is used as the App Store Marketing URL.

The privacy policy is bilingual (Polish and English) and must be checked against
the actual app and SDK behavior before each release. The contact address in the
Privacy, Terms and Support pages must be replaced before publishing.

Site routes: /, /privacy/, /terms/, /support/, /app-ads.txt.
